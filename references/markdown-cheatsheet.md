# md2pdf 支持的 Markdown 语法速查

> 只列**这个工具确实认**的写法。没列到的（例如 mermaid、数学宏包、HTML `<table>` 混排）
> 不要假设它支持。

## 标题与目录

```markdown
# 一级标题（同时是文档标题 / 打印文件名）
## 二级
### 三级
```

- 层级不许跳（`#` 直接到 `###` 会让目录错乱）。
- 「生成目录」默认开，可限定层级到 H1 / H1–H2 / H1–H3 / 全部。

## 段落与换行

- 空行分段。
- 设置里「单个换行就换行（中文习惯）」默认**开**：一个换行就断行，适合中文。
  写英文长段落时可关掉，让它按 Markdown 常规合并。

## 强调与行内

| 写法 | 效果 |
|---|---|
| `**粗**` | **粗** |
| `*斜*` | *斜* |
| `***粗斜***` | ***粗斜*** |
| `~~删除线~~` | ~~删除线~~ |
| `==高亮==` | ==高亮==（底色跟着主题色走） |
| `` `行内代码` `` | `行内代码` |
| `[文字](https://…)` | 链接（打印时可选择在链接后附网址） |
| `![图](图1.png)` | 图片（见下） |

## 列表

```markdown
- 无序
  - 嵌套（缩进两个空格）
    1. 有序也能嵌
- [ ] 待办（未完成）
- [x] 待办（已完成）
```

**续行要点**：续行缩进要**对齐列表内容的第一列**，否则会掉出列表变成普通段落。

## 表格

```markdown
| 列一 | 列二 | 列三 |
|:-----|:----:|-----:|
| 左对齐 | 居中 | 右对齐 |
```

- 每行列数必须一致（缺格会整表错位）。
- 单元格里要写 `|`，放进反引号：`` `a|b` ``。
- 列数建议 ≤ 6（A4 放得下、看得清）。
- 一行不要塞两张表；表格前后各留空行。

## 引用与分隔线

```markdown
> 引用块（左侧竖杠颜色跟主题色）

---
```

## 内置排版指令（必须独占一行）

| 写法 | 效果 | 细节 |
|---|---|---|
| `[[gap:N]]` | 空 N 行 | 1 行 = 正文行高的 1.78em；可小数；上限 200 |
| `[[gap:Nmm]]` | 空 N 毫米 | 打印精确对齐；可小数；上限 500mm |
| `[[rules:N]]` | N 条答题横线 | 每条 1.9em；取整；上限 200 |
| `[[pagebreak]]` | 强制分页 | 仅打印 / 导出 PDF 生效 |

- **必须独占一行**（这一行只写它）；混在句子里、写在代码围栏里、缩进 4 格，都会原样显示成文字。
- **不要用连续空行凑间距**：空行会被合并成段落间距，留白要写 `[[gap:…]]`。
- 单位只认 `mm` 或省略（行）；`px` / `em` 等不认。
- 写错的形式（`[[gap:]]`、`[[gap:0]]`、`[[gap:3px]]`、`[[rules:2mm]]`、`[[pagebreak:1]]`）
  不报错、不吞掉，会直接以文字出现在页面上——看到方括号原文就是写错了。
- 引用块 / 列表项里能用：`> [[gap:2]]`、`- [[gap:2]]`。

## 分页

```markdown
[[pagebreak]]
```

- 只在**打印 / 存 PDF** 时生效；屏幕预览里是一条虚线，不占空白，这是正常的。
- 别滥用；文末多留一个会多印一页空白。
- 旧写法 `<div class="page-break"></div>` 仍然兼容（老文档不用改），但新文档统一用 `[[pagebreak]]`。

## 代码块

````markdown
```js
console.log('语言标记决定高亮')
```
````

- 语言标记可选值：`js` `ts` `python` `java` `c` `cpp` `go` `rust` `bash` `json` `yaml` `sql`
  `html` `css` `diff` `text` 等常见名字。
- 不标语言 → 不高亮。
- **想显示代码而不是渲染**：标 `text`（尤其对 `html` / `css` / `svg` 内容，必须标 `text` 才不会被执行）。
- 长行会自动折行，不会裁掉；但折行不好读，控制在 80—100 字符内。

## 脚注

```markdown
正文里标记[^1]。

[^1]: 文末的脚注内容。
```

- 语法不变；**排在哪里**（文末 / 就近 / 就近 + 文末汇总）由读文档的人在设置里选。
- 需要打印时和正文同页（题包、答案页常用），提示用户把「脚注位置」设成「就近」。
- 没被正文引用过的脚注定义不会显示。

## 页面装饰（是设置项，不是 Markdown 语法）

页眉页脚、制作者头像与信息、页面背景图、每页宣传，都由读的人在设置里开，Markdown 里没有对应语法。
**不要**用重复文字、HTML `position:fixed` 或表格伪造成页脚——打印时会错位或盖住正文。
背景图要在打印界面的「背景图形」勾上才会印出来。

## 图片

```markdown
![示意图](图1.png)
```

- **本地图片**：在 md2pdf 点「打开」时，把 `.md` 和图片**一起选中**，程序按文件名自动对应
  （`![](图1.png)` 会找到同批选中的 `图1.png`）；也可以直接 `![](https://…)`。
  选过一次后图片会存进本地库，**重开同一份文档不用再选**。
- 导出 HTML 会把用到的图片打包成 data URL，所以导出的单文件发给别人也能看。
- 图片别用超大原图（几十 MB）——会拖慢预览，导出文件也会很大。

## 会被安全过滤掉的东西（别写）

- `<script>` 标签
- `onclick=` / `onerror=` / `onload=` 等事件属性
- CSS 里的 `@import`、以及指向外部的 `url(...)`
- `javascript:` 伪协议

这些在「原始 HTML 块」和渲染型围栏（`html` / `css` / `svg`）里都会被移除。
需要样式就写**内联 style** 或用 `css` 围栏定义类。

## 明确不支持

- Mermaid / PlantUML 图表 —— 用 `svg` 围栏自己画（见 layout 文档）
- 数学宏包、`\documentclass`、`\usepackage`、`\label` / `\ref` 交叉引用
- 自动编号的图表题注（自己写「图 1」）
- 目录里点击跳转的锚点在 PDF 中可用，但**外部软件打开 .md 时不保证**
