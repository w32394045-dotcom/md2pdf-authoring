# 版式、图形与打印（A4 实操）

> 这是 `SKILL.md` 的加深件：前提是你已经按它的硬规范写好了 Markdown。
> 目标：**A4 纸上看得清、印得出来、不用二次排版**。
> 屏幕预览好看 ≠ 打印好看，这份文档只讲「写的时候要注意什么 + 打印时该检查什么」。

## 一、纸面参数（默认值）

| 项 | 默认值 | 说明 |
|---|---|---|
| 纸张 | A4（210×297mm） | 也可选 Letter / A5 |
| 页边距 | 常规（18mm × 16mm） | 窄 12×10mm，宽 24×20mm |
| 正文字号 | 16px ≈ 12pt | 可调 小(14) / 中(16) / 大(18) |
| 行高 | 1.78（打印 1.72） | 适合中文长文阅读；`[[gap:N]]` 的「1 行」按 **1.78em** 计算 |

**可用宽度**：A4 常规边距下约 **174mm**，正文区约 **640px** 逻辑宽度。
写表格、SVG、`[[gap:…]]` 的横向版式时按它算。
换纸张或页边距会改变可用宽度——写死的宽表格 / 宽图在窄边距下会溢出，所以别贴着上限写。

## 二、内置排版指令（留白 / 答题横线 / 分页）

三种指令，**必须独占一行**（这一行只写它；行首不要缩进 4 格，那会变成代码块）。
混在句子里或代码围栏里都不生效，会原样显示成文字。

| 写法 | 效果 | 细节 |
|---|---|---|
| `[[gap:N]]` | 空 N 行 | 1 行 = 正文行高的 **1.78em**；N 可小数（`[[gap:2.5]]`）；上限 **200** |
| `[[gap:Nmm]]` | 空 N 毫米 | 打印对齐更精确；可小数（`[[gap:18.5mm]]`）；上限 **500mm** |
| `[[rules:N]]` | N 条答题横线 | 每条横线占 **1.9em**；N 取整；上限 **200** |
| `[[pagebreak]]` | 强制分页 | 仅打印 / 导出 PDF 生效；屏幕预览是一条虚线，不占空白 |

**正例（可整段复制）**：

```markdown
第一题……

[[rules:3]]

第二题……

[[gap:2]]

## 答案（另起一页）

[[pagebreak]]
```

**为什么会写错**：

- **连续空行凑不出间距**：Markdown 会把多个空行并成一个段落分隔，敲 5 个空行和 1 个空行效果差不多。
  要留白只能写 `[[gap:N]]` / `[[gap:Nmm]]`。
- **单位只认两个**：`mm` 或不写（按行）。`px` / `em` / `cm` / `pt` 都不认。
- **非法写法会变成普通文字**（页面上直接出现方括号原文，工具不报错）：

  | 写法 | 结果 |
  |---|---|
  | `[[gap:]]` | 缺数字，按文字显示 |
  | `[[gap:0]]` | 数量为 0，按文字显示 |
  | `[[gap:3px]]` | 单位错，按文字显示 |
  | `[[rules:2mm]]` | 横线没有毫米单位，按文字显示 |
  | `[[pagebreak:1]]` | 分页不能带参数，按文字显示 |
  | `[[gap:999]]` / `[[gap:9999mm]]` / `[[rules:999]]` | 超上限，被截到 200 行 / 500mm / 200 条 |

- **位置限制**：引用块和列表项里能用（`> [[gap:2]]`、`- [[gap:2]]`）；
  缩进 4 格会变成代码块，代码围栏里也不生效（正好用来演示语法）。
- **页首页尾小心**：开头放 `[[gap:20]]` 会顶出一大片空白；末尾多一个 `[[pagebreak]]` 会多印一页空白。

**场景建议**：

- `gap`：题与题之间 2—6 行；答案页留推导空间 20—40mm；章节之间调气口 1—2 行。
  它只是「空白」，不要拿它代替标题层级。
- `rules`：学生要手写作答的题下面放 `[[rules:2]]`—`[[rules:4]]`。
  先算一页能放多少：正文区高度约 250—260mm（A4 297mm 减上下页边距），
  题目文字 + 横线（每条 1.9em ≈ 8mm）别超过它，
  否则题和横线会被拆到两页（横线本身不参与「整块移页」）。
- `pagebreak`：只在「答案另起一页」「整章强制换页」时用。普通章节靠标题自然流动；
  表格和图片默认会尽量整块移页，不必手动切。**分页滥用 = 一堆半页纸**。

## 三、表格

| 列数 | 建议 |
|---|---|
| 2—4 列 | 舒适，随便写 |
| 5—6 列 | 可以，但单元格文字要短 |
| 7 列以上 | **拆成两张表**，或改成「名词 + 说明」的列表 |

- 每行列数必须一致，否则整表错位。
- 单元格里避免长句子（超过 20 字就该考虑拆列 / 拆表）。
- 需要对齐数字时用右对齐 `-----:`。
- 表格**不要**塞代码块或多行内容（会撑爆行高）。

## 四、图形：用渲染型围栏画 SVG

````markdown
```svg
<svg width="600" height="180" viewBox="0 0 600 180" xmlns="http://www.w3.org/2000/svg">
  <line x1="60" y1="150" x2="560" y2="150" stroke="#333" stroke-width="1.5"/>
  <line x1="60" y1="150" x2="60" y2="20" stroke="#333" stroke-width="1.5"/>
  <path d="M60,150 L560,40" stroke="#2f6fed" stroke-width="2" fill="none"/>
  <text x="570" y="155" font-size="13" text-anchor="end">t</text>
  <text x="45" y="25" font-size="13" text-anchor="end">v</text>
</svg>
```
````

**硬规范**：

1. **必须带 `viewBox` 和 `width`/`height`**。`viewBox` 决定内部坐标系，缺了会被拉伸变形。
2. **文字必须给 `font-size`**（12—14 比较合适），否则打印出来大小不可控。
3. 坐标用整数，线条用 `stroke` 不要用 `border`。
4. **配色按白底**：描边 `#2f6fed`（蓝）/ `#d64545`（红）/ `#333`（黑），填充用浅色 `#eef3ff`、`#fdf0f0`。
5. 宽高比贴近 3:1 ~ 2:1，一张图的高度最好 ≤ 120mm，否则会跨页。
6. **不要**用 `<image href="http://…">`、`<script>`、事件属性——全会被过滤。
7. 数学标注写在 SVG 里不划算；需要带公式的图，用图 + 图下公式说明。

**什么时候用 `css` 围栏**：定义可复用的盒子样式（提示框、易错框、双列对照），然后在 `html` 围栏里套。

````markdown
```css
.tip{border-left:4px solid #2f6fed;background:#eef3ff;padding:10px 14px;border-radius:6px}
.bad{border-left:4px solid #d64545;background:#fdf0f0;padding:10px 14px;border-radius:6px}
```

```html
<div class="tip"><b>提示</b>：先受力分析，再列方程。</div>
<div class="bad"><b>易错</b>：忘了摩擦力方向。</div>
```
````

**什么时候用 `text`**：想展示 HTML/CSS 代码本身，而不是让它生效。

## 五、分页与旧写法兼容

**推荐**（新文档统一用这个）：

```markdown
[[pagebreak]]
```

- 只在打印 / 导出 PDF 生效；屏幕预览里是一条虚线，不占空白，属正常现象。
- 别滥用：整页只有两三行时再分页，否则浪费纸。
- 表格和图片默认**不分页断开**（内部会尽力整块移页），所以不必自己切。
- 文末不要多留一个，会多印一页空白。

**旧写法仍兼容**（老文档照常能渲染，不用改；但不要再教别人这么写）：

```markdown
<div class="page-break"></div>
```

`page-break` 不是「唯一的分页方式」，现在写 `[[pagebreak]]` 更短、更不容易混进段落。

## 六、脚注与每页装饰（打印相关）

**脚注**：写作侧只写 `[^1]`（正文标记 + 文末定义），语法不变。
排在哪里由读的人在设置里选：

| 模式 | 打印效果 | 适用 |
|---|---|---|
| 文末（默认） | 全部集中在文档最后 | 注释少、偏参考文献 |
| 就近 | 插在引用它的段落后面，**与正文同页** | 题包、答案页、试卷讲评——最实用 |
| 就近 + 文末汇总 | 两处都有 | 既要同页看，又要文末总表 |

**每页装饰**（制作者信息 / 每页宣传）是设置项，Markdown 里不要伪造。用户开了之后：

- 打印时装饰**固定贴在页边**，每页重复；内容很密时会压住正文。
- 解决办法：调大页边距，或把位置改成「顶部 / 底部」（只在文档首尾出现一次）。
- 作者信息和「每页宣传」都在底部时会合并成一个容器，不会互相盖住——这是工具行为，不用你处理。

## 七、打印检查清单（出 PDF 前逐条过）

1. 浏览器用 Chrome / Edge；目标选「**另存为 PDF**」。
2. 打印界面里按需勾选：
   - [ ] 「**背景图形**」——文档设了页面背景图时必须勾，否则纸上没有背景。
   - [ ] 「页眉和页脚」——需要页码时勾（页码由浏览器加）。
3. 纸张 / 页边距与设置一致（A4 常规约 174mm 可用宽）。
4. 预览里没有溢出：宽表已拆、SVG 没超宽、长代码行折行后仍可读。
5. 分页符合预期：答案页真的另起、末尾没有空白页。
6. 每页装饰没压住正文（内容密就调大页边距，或改成「顶部 / 底部」单次出现）。
7. 需要同页注释的文档，脚注位置已设成「就近」。
8. 本地图片都显示出来了（首次打开时把 `.md` 和图片一起选中，之后会存进本地库）。

**常见打印问题**：

| 现象 | 原因 / 修法 |
|---|---|
| 背景没印出来 | 打印界面没勾「背景图形」 |
| 每页页脚压住正文 | 内容密 + 每页装饰贴边；调大页边距或改单次出现 |
| 脚注和正文不在同一页 | 脚注位置是「文末」；改成「就近」 |
| 多出空白页 | 末尾多余的 `[[pagebreak]]`，或首尾 `[[gap:…]]` 太大 |
| 页面上出现 `[[gap:3]]` 原文 | 指令没独占一行 / 单位写错 / 超上限被截断（见第二节） |
| 表格被切一半 | 列太多；拆表 |
| 图片模糊 | 用的是位图且被拉伸；改 SVG |
| 中文字体变成宋体 / 黑体 | 没设置字体或导入字体；在设置里选，或用系统字体栈 |
| 页码没有 | 打印界面里没开「页眉和页脚」 |
| 打印是黑纸 | 旧版本主题色问题；用最新版，打印自动转白底 |

## 八、导出独立 HTML

点「📄 导出 HTML」→ 得到**一个自包含 HTML**：

- 样式、用到的字体、本地图片都打包进文件（图片转 data URL）。
- 别人双击就能看，不用装任何东西，也不联网。
- 体积会比 `.md` 大很多（字体尤其明显）——分发给别人时提醒一句。
- 排版装饰、背景、每页装饰会随导出一起带上（和打印同源）。

## 九、写长文档的结构建议

1. 开头一个 `#` 标题 + 一段 3—5 行的摘要（说明这是什么、给谁看）。
2. 用 `##` 分大块，`###` 分小节；**别超过三层**。
3. 每块开头一句话说清这节要解决什么。
4. 代码 / 公式 / 表格 / 指令前后各留空行，排版才不挤。
5. 结尾给「小结」或「检查清单」，长文档最容易丢的是结尾。

## 十、界面语言（7 种）与示例模板

顶栏「🌐」下拉框：简体中文 / 繁體中文 / 日本語 / 한국어 / Deutsch / Français / English。
首次打开按浏览器语言自动匹配，选择存在浏览器里。

**三条容易搞错的关系**：

| 事实 | 含义 |
|---|---|
| 界面语言 ≠ 文档语言 | 换界面只改按钮和提示，**不会**翻译或改动正文；中文文档配英文界面照样排版正常 |
| 切换语言默认整页刷新 | 最稳：所有文字、菜单、示例按新语言重建。用户看到「闪一下」是正常的；可在设置里关掉，改为就地替换文字 |
| 示例文档跟着语言换 | 7 种语言各一份手写样例；只在「当前内容正好是示例」时才替换，**不会动用户自己写的文档** |

**示例模板的用法**：点「示例」按钮，当前语言那份就是本 Skill 规范的活样板
（表格 / 围栏 / 公式 / `\ce` / 渲染型图形 / 脚注 / 排版指令 / 分页齐全，也点到了背景、每页装饰等设置项）。
用户问「照这个格式来」时，让他直接看示例，比自己复述规则有效；自己不确定某写法渲染成什么样，也先翻示例。

**打印 / 导出与语言无关**：换界面语言不会改变纸张、字号、主题色，也不会影响 PDF 里的文字与字体。
